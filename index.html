HTML5 Boilerplate remixed by Morgan

Hello world! These are some HTML5 Boilerplate Files. I removed a few things and added a few things. The goal is that it could be useful and will always be less than 100kb in size.

  • Download v0.1-remixed-boilerplate.zip
What is boilerplate? I have always thought of boilerplate as "the stuff that helps getting started" that can sometimes be repetitive or clunky. Some code can be repetitive setting up new projects, and that you might forget some of it if its a small custom project. This is just my flavor of website boilerplate for a small website.

What did I keep?

  • Basic HTML and CSS boilerplate, placeholder Favicon, SVG Icon, placeholder web manifest

What did I get rid of?

  • I got rid of the build system using Parcel that required the project to have a package.json. This project is intended be launched statically, with no built or bundling involved.
  • I trimmed back a few more things, like open graph tags. I dont really like them, and would not make them for every project.

What did I add?

  • Fluid Typography from Utopia project
  • Very basic CSS to present the content pattern with a main element
